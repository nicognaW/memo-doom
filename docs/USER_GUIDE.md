# 用户指南

进入应用，允许显示和连接事件权限。点「启动 DOOM」，等菜单/演示出现；用「菜单」进入菜单，「确认」逐级选择新游戏、章节和难度。方向按钮也用于菜单移动。

| 目的 | 操作 |
| --- | --- |
| 前进/后退/转向 | 按住对应方向，松开停止 |
| 横移 | 点开横移开关，再用左右键；再次点按关闭 |
| 奔跑 | 点开奔跑开关，再操作方向键 |
| 射击 | 按住开火，松开停止，无自动开火开关 |
| 开门/阵亡重开 | 点「使用」 |
| 切枪 | 点已拥有的武器槽；1/3 号槽按引擎规则兼容两种武器 |
| 地图、菜单/确认、是/否 | 点相应按钮 |
| 暂停/继续 | 点暂停或继续；断连后不会自动恢复 |

手机 HUD 显示真实生命（可大于 100）、护甲、当前武器与其弹药池、钥匙。拳头/电锯不耗弹药；BFG 不足 40 能量、双管霰弹枪不足 2 发也算缺弹。低于等于 25 生命提示低血量。菜单/结算不把过期值当作当前战斗数据，演示、暂停、断连均有提示。

眼镜保留原游戏 HUD，手机提供清晰的大字补充。默认流畅档降低细节但保留视野和显示尺寸；原生更清楚但链路负载通常更大。连接与诊断默认折叠，需要排查再展开。

可选文件/存储权限用于导入自有 IWAD；拒绝后仍可玩内置 Freedoom。只支持完整 IWAD，不支持 PWAD。选文件取消不会替换当前资源；重启可以恢复文件引用，但不会恢复游戏进度。

隐藏页面、失焦、暂停和断连会释放所有输入并关闭横移/奔跑。重新连接后点继续再玩。卡住移动或自动持续射击不属于预期行为，请记录操作及诊断信息报告。
