# Decision records

Recorded on 2026-10-25, after the user accepted version 0.1.5. These are retrospective records based on the development conversation and the accepted source tree. They are not contemporaneous meeting minutes or a reconstruction of missing Git history.

The review uses the supplied grilling, retro and domain-modeling skills: separate facts from choices, trace a choice to an observation, and check the result against code. Matt Pocock is a reference for the requested review approach, not an author, reviewer or participant in this project.

- [Iteration record](iteration-record.md): observed feedback, changes, reversals and open questions.
- [Retrospective](../retrospective.md): environment improvements, ordered by severity.
- [ADR 0001](../adr/0001-phone-engine-and-glasses-view.md): phone engine and glasses companion boundary.
- [ADR 0002](../adr/0002-send-the-latest-frame.md): freshness over a queue of old images.
- [ADR 0003](../adr/0003-external-platform-dependencies.md): public source and external platform components.

ADRs record the current architectural commitments. Reversible interface changes, such as the fire button, belong in the iteration record. The [glossary](../../GLOSSARY.md) defines the language; implementation details belong in the [architecture](../ARCHITECTURE.md).
