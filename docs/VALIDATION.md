## 已有真机反馈

用户反馈流畅档相较早期版本明显改善。一次用户截图显示 JS 后端、近期完成约 6.0 帧/秒、单帧 10.3 KiB、发送 142 ms、错误 0；早期原生档截图约 2.3 帧/秒、19.8 KiB、445 ms。这些是不同场景下的宿主统计快照，不是受控基准，也不等同于面板实测刷新率。

用户随后明确停止帧率优化，转向 HUD 和触控 UX，并在修正开火按压行为后确认达到其认可的发布标准。此次源码整理没有进行新的实体手机/眼镜测试，不能宣称公开版二进制已重新完成真机安装验收。

## 平台侧历史限制

外部 SDK 公共全集存在与本应用无关的 Display Control Lab 版本断言失败，未修改该示例来消除失败。本仓库只报告应用自己的 34 项测试通过，不将外部全集描述为全绿。

既有接受安装包曾核对 Studio AB ZIP 的实际组件及 review 哈希；旧检查工具对 review v3 的限制见 [INSTALL.md](INSTALL.md)。公开仓库不携带原始安装 QR 或内部导出附件。
